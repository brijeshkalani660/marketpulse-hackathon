# marketpulse-hackathon
MarketPulse asks: can news help predict the stock market? By Brijesh Kalani, Krishay Ranawat and Nandan Ranganathan. We tested price-based estimates on 400 stocks: direction right 55.0% of the time vs 50.3% for always guessing up. A small edge, not a guarantee. Built with Claude’s help. For learning only, not financial advice.
